# DASH OrthoFlow Windows 다운로드

[최신 배포 파일](https://github.com/seraph489/DASH-OrthoFlow-Releases/releases/latest/download/DASH-OrthoFlow-windows.zip)

ZIP 압축을 풀고 Setup.cmd로 설치 준비 후 DASH-OrthoFlow.exe를 실행하세요.
기존 사용자는 앱을 종료한 뒤 프로그램 폴더를 교체하세요. 사용자 설정은 별도 Windows 사용자 폴더에 보관됩니다.

각 Release의 SHA256SUMS.txt에서 파일 체크섬을 확인할 수 있습니다.
코드서명 여부는 release-manifest.json의 signature 항목과 릴리스 설명에 명시됩니다.
이 저장소는 완성된 Windows 배포 파일 전용입니다. 소스 코드와 병원 자료는 포함하지 않습니다.
